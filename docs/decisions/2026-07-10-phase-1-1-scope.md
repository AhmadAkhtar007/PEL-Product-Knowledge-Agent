# Phase 1.1 Scope: PEL Product Knowledge Agent

Phase 1.1 is a citation-backed public PEL product knowledge agent.

- The existing `customer-app` remains the starting point for the Android experience.
- Ticketing and technician work are out of the active Phase 1.1 scope.
- The original structured PEL knowledge corpus is retained as the source material for the agent.

This phase demonstrates grounded retrieval and source citations from PEL's public product information. It does not replace PEL's existing service or complaint infrastructure.
